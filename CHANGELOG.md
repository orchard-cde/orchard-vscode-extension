# Changelog

## 0.1.0 (Unreleased)

### Added
- Grove lifecycle management (create, connect, stop, start, delete)
- Activity Bar sidebar with real-time grove status
- SSH Remote connection to flourishing groves
- Server-Sent Events for live status updates
- Configurable Trellis server connection
- Trowel CLI auto-detection
- `Orchard: Sign In` and `Orchard: Sign Out` commands that authenticate to Trellis through the fence device flow
- Orchard account in the VS Code Accounts menu

### Changed
- Requires VS Code 1.101 or later
- Replaced the cultivator-id setting with fence sign-in
